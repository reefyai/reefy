# Change review and vendor patches

Changes to this repository must be proposed through a pull request. Do not
push changes directly to the default branch. Ask the user to review the pull
request, and do not merge without explicit user authorization.

Do not add or modify patches to third-party C/C++ source without explicit user
approval for that patch. First investigate stock tooling and configuration,
provide a reproducer, and explain necessity, maintenance and performance impact.
General authorization to fix a bug does not authorize a vendor source patch.
